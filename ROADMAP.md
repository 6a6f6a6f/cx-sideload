# Roadmap

The initial release stays small, dependency-free, and macOS-focused.

## Hardening

- [ ] Publish a concise threat model.
- [ ] Add a reproducible MSI test fixture.
- [ ] Expand CrossOver version and installation-path coverage.
- [ ] Add release checksums and signed tags.

## Usability

- [ ] Add interactive bottle selection.
- [ ] Support copying portable executables into a bottle.
- [ ] Create optional CrossOver launchers and menu entries.
- [ ] Improve diagnostics for unsupported installer formats.

## Distribution

- [ ] Add a Homebrew formula.
- [ ] Add versioned releases.
- [ ] Add Linux support after validating CrossOver's Linux layout and behavior.
- [ ] Add CI for ShellCheck and tests after the local contract stabilizes.

Roadmap items are proposals, not compatibility guarantees.
